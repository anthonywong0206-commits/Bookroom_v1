# 房間及物品預約系統（手機版介面更新）

這個版本按最新概念圖重做了**用戶介面**，以手機使用為主，採用大按鈕、底部導航列，以及更清晰的借用流程。

## 目前已完成功能

### 首頁
- 只顯示兩個主按鈕：**預約**、**查詢**
- 手機優先版面
- 固定底部導航列：**首頁 / 預約 / 查詢 / 我的**

### 預約流程
#### 1) 房間預約
流程：
1. 選擇房間
2. 以日曆選擇日期
3. 選擇借用時段（可多選）
4. 詢問是否需要同日借用物品
5. 如需要，選擇只可在中心即日使用的物品及數量
6. 填寫用途、姓名、電話等資料並提交

#### 2) 外借物品
流程：
1. 選擇借用開始日期
2. 系統預設借用期為 **一星期**
3. 可自行修改歸還日期
4. 選擇外借物品及數量
5. 填寫用途、姓名、電話等資料並提交

### 查詢 / 我的申請
- 可用關鍵字或申請編號搜尋
- 可查看示範狀態：待審批 / 已批准 / 已歸還
- 新提交申請會即時記錄到本機瀏覽器 `localStorage`

## 部署方式

這個版本是**純前端靜態網站**，可直接部署到：
- GitHub Pages
- Vercel
- Netlify

### GitHub Pages / Vercel
只需把整個資料夾上載到 repository root 即可。
